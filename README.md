# WasMusicore

一个使用WEB前端技术，融合 electron + Vite + Vue3 + element plus 的跨端桌面程序Music工具DAW集成。

- 官网: [https://](https://)
- 代码: [https://](https://)

## 技术栈

- 编码工具：Visual Studio Code
- 前端技术：vite^6.0.3+vue^3.5.13+vue-router^4.5.0
- UI组件库：element-plus^2.9.5
- 跨端框架：electron^35.0.0
- Electron 打包工具：electron-builder^25.1.8
- Electron Vite插件：vite-plugin-electron^0.29.0

## 安装依赖

```bash
pnpm install

# npm install
# yarn install
```

### 开发运行

```bash
bash ./wasm_rust/build.sh
pnpm run dev

#npm run dev
```

### 打包EXE

```bash
pnpm run build

#npm run build
```

## 拉取代码

```bash
git clone https://gitee.com/slamkun/WasMusicorElectron.git
cd WasMusicorElectron
npm i
npm run dev
```
